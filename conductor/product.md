# Initial Concept
A professional-grade 3D house builder application for DIY Home Builders and Renovators in Sweden. It uses a 2D floor plan as the single source of truth to derive 3D models and municipality-ready documents (bygglov).

# Product Guide

## Target Users
- **DIY Home Builders/Renovators:** Non-professionals who want to visualize their renovation or new build ideas and generate the necessary technical documentation for building permit applications without needing complex CAD software.

## Primary Goals
- **Simplified Planning:** Provide an intuitive interface for creating accurate floor plans that doesn't require professional training.
- **Regulatory Compliance:** Automate the alignment with Swedish "bygglov" (building permit) requirements, ensuring that designs are architecturally sound and municipality-ready.

## Key Features
- **Intelligent Drawing Tools:** Features smart snapping and automatic room detection from wall loops, making the drawing process fast and error-free.
- **Automated Document Export:** One-click generation of PDF drawings (Planritning, Fasadritning, Sektionsritning) formatted specifically for Swedish municipal standards.
- **Real-time 3D Preview:** Instant, high-quality visualization of the 2D plan in a 3D environment, allowing users to understand volume, space, and light immediately.

## Regulatory Integration
- **Automated Validation:** Provides real-time feedback on common regulatory issues such as minimum room areas and accessibility requirements.
- **Template-Based Documents:** Ensures all exported documents adhere to the standardized formats expected by Swedish authorities.
- **Guided Configuration:** Interactive walkthroughs to help users fill in the metadata required for building permit applications.

## User Experience Focus
- **Instant 3D Transition:** A seamless experience switching between 2D sketching and a fully realized 3D model.
- **Automated Intelligence:** Rooms are instantly labeled and areas are calculated the moment a wall loop is closed.
- **Professional Credibility:** The primary "wow factor" is seeing a professional-grade blueprint generated from a simple, user-friendly sketch.
